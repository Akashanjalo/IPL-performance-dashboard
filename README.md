# IPL Performance Dashboard

This project is an interactive Power BI dashboard analyzing player and team performance across IPL seasons (2008–2020).

## Dataset
- Source: [Kaggle - IPL Dataset](https://www.kaggle.com/datasets/patrickb1912/ipl-complete-dataset-20082020)
- Files used:
  - `matches.csv`
  - `deliveries.csv`

## Features
- Top 10 run scorers and wicket takers
- Team performance by season
- Match winners and toss analysis
- Player of the Match awards
- Interactive filters (team, season, player)

## Tools Used
- Power BI
- DAX for measures
- Excel for preliminary inspection

## Insights

- CSK had one of the highest win rates across seasons.
- Virat Kohli consistently ranked among top scorers.
- Bowlers like Bhuvneshwar Kumar and Bumrah were top wicket-takers.

## How to Use
Download the `.pbix` file and open in Power BI Desktop to explore the visuals interactively.
